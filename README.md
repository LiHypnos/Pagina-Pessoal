## ♿ Acessibilidade

- **Deuteranopia** – paleta segura para daltonismo vermelho-verde
- **Tritanopia** – paleta segura para daltonismo azul-amarelo
- **Alto Contraste** – maximiza legibilidade em ambos os temas
- **Texto Grande** – aumenta fonte base para 120%
- **Focus visível** – outline de 3px em todos os elementos interativos (WCAG 2.1 AA)

## 🌍 Internacionalização
